# 1. What is the difference between null and undefined?

| **undefined**                                           | **null**                                              |
| ------------------------------------------------------- | ----------------------------------------------------- |
| ভেরিয়েবল ডিক্লেয়ার করা হয়েছে কিন্তু মান দেওয়া হয়নি | ইচ্ছাকৃতভাবে কোন মান নেই সেট করা হয়েছে               |
| ফাংশন কিছু রিটার্ন না করলে undefined রিটার্ন করে        | এটি একটি asign করা মান                                |
| অবজেক্টের প্রপার্টি exist না করলে undefined             | ডেভেলপার নিজে null সেট করে                            |
| টাইপ: `"undefined"`                                     | টাইপ: `"object"` (এটি জাভাস্ক্রিপ্টের একটি পুরনো bug) |

# 2. What is the use of the map() function in JavaScript? How is it different from forEach()?

## map()

| বৈশিষ্ট্য          | বর্ণনা                                    |
| ------------------ | ----------------------------------------- |
| **রিটার্ন ভ্যালু** | একটি **নতুন array** রিটার্ন করে           |
| **অরিজিনাল array** | অপরিবর্তিত থাকে                           |
| **চেইনিং**         | করা যায় (`.map().filter().reduce()` etc) |
| **ব্যবহার**        | ডাটা transformation এর জন্য               |

## forEach() এর বৈশিষ্ট্য

| বৈশিষ্ট্য          | বর্ণনা                                                    |
| ------------------ | --------------------------------------------------------- |
| **রিটার্ন ভ্যালু** | কিছু রিটার্ন করে না (**undefined**)                       |
| **অরিজিনাল array** | পরিবর্তন করতে পারে (side effects)                         |
| **চেইনিং**         | করা যায় না                                               |
| **প্যারামিটার**    | currentValue, index, array                                |
| **ব্যবহার**        | side effects এর জন্য (console.log, DOM manipulation, etc) |

# 3. What is the difference between == and ===?

## মূল পার্থক্য

| **বৈশিষ্ট্য**         | **== (Abstract Equality)** | **=== (Strict Equality)**      |
| --------------------- | -------------------------- | ------------------------------ |
| **চেক করে**           | শুধু **মান** চেক করে       | **মান এবং টাইপ** দুটোই চেক করে |
| **টাইপ কনভার্শন**     | করে (type coercion)        | করে না                         |
| **'5' == 5**          | **true**                   | **false**                      |
| **null == undefined** | **true**                   | **false**                      |
| **1 == true**         | **true**                   | **false**                      |
| **0 == false**        | **true**                   | **false**                      |
| **'' == 0**           | **true**                   | **false**                      |

# 4. What is the significance of async/await in fetching API data?

**async/await হলো JavaScript-এ asynchronous (অ্যাসিনক্রোনাস) কোড লেখার একটি আধুনিক পদ্ধতি। এটি ES2017 (ES8) এ introduced হয়। async/await ব্যবহার করে আমরা asynchronous কোডকে synchronous (সিনক্রোনাস) কোডের মতো দেখতে এবং আচরণ করাতে ব্যবহ্ত হয়।**

# 5. Explain the concept of Scope in JavaScript (Global, Function, Block).

**জাভাস্ক্রিপ্টে স্কোপ বলতে বোঝায় যে, কোডের কোন অংশ থেকে ভ্যারিয়েবল বা ফাংশন অ্যাক্সেস করা যাবে। এটি মূলত ভ্যারিয়েবলের দৃশ্যমানতা নিয়ন্ত্রণ করে।**

**প্রধানত তিন ধরনের স্কোপ রয়েছে:**

## _Global Scope (গ্লোবাল স্কোপ):_

**যেসব ভ্যারিয়েবল কোনো ফাংশন বা ব্লকের বাইরে ডিক্লেয়ার করা হয়, সেগুলো গ্লোবাল স্কোপের অধীনে থাকে।**
**এই ভ্যারিয়েবলগুলো প্রোগ্রামের যেকোনো জায়গা থেকে অ্যাক্সেস করা যায়।**
**var, let, এবং const দিয়ে গ্লোবালি ডিক্লেয়ার করা ভ্যারিয়েবল একইভাবে কাজ করে, যদিও let এবং const ব্রাউজারের window অবজেক্টের অংশ হয় না।**

## _Function Scope (ফাংশন স্কোপ):_

**ফাংশনের ভেতরে ডিক্লেয়ার করা ভ্যারিয়েবলগুলো ফাংশন স্কোপের অন্তর্ভুক্ত।**
**এগুলো শুধুমাত্র সেই ফাংশনের ভেতর থেকেই অ্যাক্সেস করা যায়, বাইরে থেকে নয়।**
**var, let, এবং const - সব ধরনের ডিক্লারেশনই ফাংশনের ভেতরে লোকাল হিসেবে কাজ করে।**

## B*lock Scope (ব্লক স্কোপ):*

**ES6-এ (let এবং const আসার পর) ব্লক স্কোপের ধারণা চালু হয়।**
**if স্টেটমেন্ট, for লুপ বা যেকোনো {} (কার্লি ব্রেসেস) ব্লকের ভেতরে let বা const দিয়ে ডিক্লেয়ার করা ভ্যারিয়েবলগুলো শুধুমাত্র সেই ব্লকের মধ্যেই সীমাবদ্ধ থাকে।**
**var কিওয়ার্ড ব্লক স্কোপ মেনে চলে না; এটি ফাংশন স্কোপ বা গ্লোবাল স্কোপ পর্যন্ত বিস্তৃত হয়।**
